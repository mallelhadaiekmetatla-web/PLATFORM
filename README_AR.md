# برنامج إدارة المنتجات والأسعار — PostgreSQL

## الميزات
- صفحة دخول محمية بحساب أدمين.
- إدارة المنتجات: إضافة، تعديل، حذف، بحث بالاسم أو الباركود.
- عرض المنتجات في جدول أو بطاقات.
- البحث الفعلي من قاعدة البيانات؛ لا تتم قراءة Excel عند كل بحث.
- استيراد Excel وتخزين البيانات في قاعدة البيانات، مع تحديث المنتج الموجود عند تطابق الباركود.
- اكتشاف الملف المطابق تمامًا عبر SHA-256 وعدم استيراده مرة أخرى دون داعٍ.
- إعدادات اسم المتجر واللوغو والعملة ومقاس بطاقة السعر.
- بطاقة سعر قابلة للطباعة بمقاسات متغيرة، مع خيار إظهار الباركود أو إخفائه.
- واجهة مسح باركود بكاميرا الهاتف.
- PostgreSQL على Render، وSQLite محليًا لتجربة سريعة عند عدم إعداد DATABASE_URL.

## تشغيل محلي على Windows 11
1. ثبّت Python 3.11 أو أحدث.
2. افتح مجلد المشروع في Terminal.
3. أنشئ بيئة افتراضية:
   `py -m venv .venv`
4. فعّلها:
   PowerShell: `.\.venv\Scripts\Activate.ps1`
5. ثبّت المتطلبات:
   `pip install -r requirements.txt`
6. انسخ `.env.example` إلى `.env`، ثم غيّر `SECRET_KEY` و`ADMIN_PASSWORD`.
7. شغّل:
   `python app.py`
8. افتح `http://127.0.0.1:5000`

في التشغيل المحلي الأول، إذا لم تضع DATABASE_URL فسيستخدم البرنامج قاعدة SQLite محلية للتجربة. لتجربة PostgreSQL محليًا، ضع رابط PostgreSQL في DATABASE_URL.

## رفعه إلى Render مع PostgreSQL
1. أنشئ قاعدة PostgreSQL في Render.
2. انسخ Internal Database URL (إذا كان التطبيق وقاعدة البيانات في Render نفسها) أو رابط الاتصال المناسب.
3. ارفع محتويات المجلد إلى مستودع GitHub.
4. أنشئ Web Service من المستودع، ويمكنك استخدام `render.yaml`.
5. عيّن متغيرات البيئة:
   - `DATABASE_URL`: رابط PostgreSQL.
   - `SECRET_KEY`: قيمة عشوائية طويلة.
   - `ADMIN_USERNAME`: اسم دخول الأدمين.
   - `ADMIN_PASSWORD`: كلمة مرور قوية وفريدة.
6. انشر التطبيق. تُنشأ الجداول تلقائيًا عند بدء التشغيل الأول.

## تسجيل الدخول
القيم الافتراضية المحلية في `.env.example` مثال توضيحي فقط. غيّر كلمة المرور قبل نشر التطبيق على الإنترنت.

## ملف Excel
- ارفع الملف من صفحة «الإعدادات والاستيراد».
- تتم قراءة الورقة الأولى.
- يحاول البرنامج التعرف على أعمدة الباركود والاسم والسعر، مع أسماء شائعة بالعربية والإنجليزية والفرنسية.
- يجب أن يحتوي الملف على عمود اسم المنتج وعمود السعر. الباركود موصى به بشدة.
- عند وجود باركود مطابق يتم تحديث المنتج الموجود؛ وعند عدم وجوده تتم إضافة منتج.
- إذا لم يكن للصف باركود، لا يستطيع البرنامج التأكد أنه المنتج نفسه، لذلك قد ينشئ صفًا جديدًا عند إعادة استيراد ملف مختلف. استخدم باركودًا فريدًا لكل منتج لتجنب ذلك.
- الملف المطابق تمامًا لا يعاد استيراده. أما الملف المعدل فيعاد تحليله وتحديث المنتجات.
- المنتجات غير الموجودة في الملف لا تحذف تلقائيًا.
- استيراد ملف Excel لا يحدث تلقائيًا عند كل تسجيل دخول؛ فالبيانات المستوردة محفوظة في قاعدة البيانات. عند تحديث الملف، ارفعه مرة أخرى لتطبيق التحديثات.

## ملاحظات مهمة
- قاعدة البيانات هي مصدر البحث بعد الاستيراد.
- الطباعة تستخدم إعدادات المتجر المحفوظة في قاعدة البيانات.
- شعار المتجر وصور المنتجات المرفوعة تحفظ في مجلد static/uploads. في بيئة Render ذات القرص المؤقت، أضف Persistent Disk أو انقل الصور إلى تخزين دائم حتى لا تختفي بعد إعادة النشر.
- هذا إصدار أساس عملي، ويجب ضبط النسخ الاحتياطي وكلمات السر قبل الاستخدام التجاري الفعلي.
